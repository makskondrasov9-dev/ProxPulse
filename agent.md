# agent.md — Регламент разработки ProxPulse v0.2.0

## Описание проекта
Нативное клиентское приложение под macOS (Swift 6, SwiftUI, macOS 14+) для мониторинга и администрирования Proxmox VE.

## Архитектура и стек
- Архитектура: MVVM, сервисный слой на async/await, нативный SwiftUI без сторонних UI-библиотек.
- Хранение секретов: Apple Keychain (только токены и пароли).
- Пользовательские пресеты и настройки: UserDefaults / Application Support (JSON).
- Виджеты: WidgetKit (Small, Medium, Large) с синхронизацией через App Group (group.proxpulsedata).
- Сеть: URLSession с поддержкой самоподписанных SSL-сертификатов.

## Спецификация v0.2.0

### 1. Режимы отображения (Workspace View Modes)
- Сегментированный переключатель в шапке над списком машин: Сетка, Стойка, Карта.
- Плавная физика переключения (.spring).
- Полный паритет функционала: клик по машине в любом режиме открывает единый Inspector Sheet (6 графиков, телеметрия, Start/Stop/Reboot, консоль, удаление).

### 2. Фронтальная серверная стойка (Front Rack View)
- Реалистичный 19" серверный шкаф с металлическими направляющими и нумерацией юнитов (U).
- 1U для LXC, 2U для QEMU VM.
- На лицевой панели: имя, vmid, OLED-микроиндикаторы (CPU/RAM), лампа статуса (зеленый online, серый offline), анимированные светодиоды сетевой активности (Tx/Rx Activity LEDs, частота мигания привязана к netin/netout).
- Быстрые кнопки управления при наведении (hover).

### 3. Интерактивная карта топологии (Interactive Topology Canvas)
- Центральный узел: нода Proxmox с кольцами активности.
- Неоновые линии к мостам (vmbr0) и далее к узлам контейнеров и виртуалок.
- Автодетект туннелей: проверка сетевых интерфейсов ноды (/api2/json/nodes/{node}/network) на наличие awg*, wg*, tun*.
- Отрисовка отдельной пульсирующей линии туннеля к удаленному шлюзу с отображением пинга и пропускной способности.
- Анимированные световые частицы вдоль связей, скорость движения которых зависит от текущего сетевого трафика.

### 4. Мастер создания VM и LXC (Proxmox-Grade Wizard)
- Полная точность параметров API Proxmox:
  * LXC: VMID (автоподбор свободного через /cluster/nextid), Hostname, Unprivileged, Nesting, пароль/SSH-ключи, выбор шаблона (vztmpl со storages), диск (storage, размер GB), CPU cores, RAM, Swap, Network (vmbr0, DHCP/Static, GW, Firewall), DNS.
  * VM: VMID (автоподбор), Name, ISO (выбор образов iso со storages), Qemu Agent, диск (bus virtio/scsi, storage, size, discard), CPU (sockets, cores, type), Memory (RAM, ballooning), Network (bridge, model virtio, firewall).
- Система пресетов: сохранение текущей конфигурации формы в именованный пресет и автозаполнение из выпадающего списка.

### 5. Безопасное удаление машин (Destroy Guard)
- Защита от случайного удаления: модальное окно с обязательным ручным вводом номера VMID или имени машины для разблокировки действия.
- API: DELETE /api2/json/nodes/{node}/{type}/{vmid}?purge=1.
