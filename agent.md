# agent.md — Регламент разработки macOS-клиента ProxPulse

## Концепция продукта
Премиальный нативный клиент Proxmox VE для macOS (Swift 6, SwiftUI, macOS 14+).
Фокус: первоклассный дизайн в стиле Apple (Liquid Glass, многослойные кольца активности, глубокий интерактивный дисковый радар, плавная пружинная анимация).

## Отношение к референсу (MacPulse)
- Проект MacPulse (https://github.com/makskondrasov9-dev/MacPulse) используется СТРОГО READ-ONLY.
- Из MacPulse брать ТОЛЬКО архитектуру фонового опроса, MenuBarExtra и таймлайны WidgetKit.
- ВИЗУАЛ ИЗ MACPULSE НЕ КОПИРОВАТЬ: весь UI, компоненты, карточки и диаграммы строятся с нуля по современным гайдлайнам Apple Human Interface Guidelines.

## Дизайн-система ProxPulse
- Цвета: глубокая темная тема, адаптивная светлая, яркие системные акценты (Electric Blue, Emerald Green, Amber Warning, Crimson Error).
- Материалы: .ultraThinMaterial, тонкие градиентные обводки (stroke 0.5-1pt), эффект свечения (glow).
- Метрики: Apple-style Activity Rings (кругляшки нагрузки CPU, RAM, Disk, Network) с плавной физикой (.spring).
- Дисковый радар: многослойный интерактивный радиальный визуализатор с поддержкой раскрытия уровней и анимацией перехода.

## Архитектура и безопасность
- Универсальность: поддержка нескольких серверов (Multi-node / Multi-cluster).
- Токены Proxmox API хранятся в Apple Keychain.
- Сеть: URLSession async/await с поддержкой самоподписанных SSL-сертификатов.
- Движок диагностики «Что случилось?»: логические сценарии сбоев без стороннего ИИ.
